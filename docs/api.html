LiquidGlassView

The primary component for creating liquid glass effects. It renders a div with backdrop-filter effects that create a frosted glass appearance.

Import

import { LiquidGlassView } from '@liquid-glass/react';

Props

Prop Type Default Description
effect 'regular' | 'clear' | 'none' 'regular' Visual effect mode:
• regular - Standard frosted glass with strong blur
• clear - More transparent, subtle blur
• none - No glass effect (for transitions)
interactive boolean false Enables hover and press interaction effects including scale transforms and shimmer animation.
colorScheme 'light' | 'dark' | 'system' 'system' Color scheme preference:
• system - Follows OS preference
• light - Force light appearance
• dark - Force dark appearance
tintColor string undefined Optional color tint overlay. Accepts any valid CSS color (hex, rgb, rgba, named colors).
children ReactNode - Content to render inside the glass container.
className string - Additional CSS class names.
style CSSProperties - Inline styles. Commonly used for padding, borderRadius, etc.

Basic Example

Weather Widget

import { LiquidGlassView } from '@liquid-glass/react';

function WeatherWidget() {
  return (
    <LiquidGlassView
      effect="regular"
      interactive
      colorScheme="dark"
      style={{
        padding: 20,
        borderRadius: 20,
        minWidth: 180,
      }}
    >
      <p>San Francisco</p>
      <p style={{ fontSize: 48 }}>72°</p>
      <p>☀️ Sunny</p>
    </LiquidGlassView>
  );
}

With Tint Color

Tinted Glass Button

<LiquidGlassView
  effect="clear"
  tintColor="#ff6b6b"
  interactive
  style={{ padding: '16px 32px', borderRadius: 16 }}
>
  <span>Hot Deal! 🔥</span>
</LiquidGlassView>

Note: For best results, place the LiquidGlassView over colorful or image backgrounds. The glass effect is most visible when there's content behind it to blur.

LiquidGlassContainerView

A container component that groups multiple glass elements together. When glass children are within the specified spacing distance, their effects can visually merge.

Import

import { LiquidGlassContainerView } from '@liquid-glass/react';

Props

Prop Type Default Description
spacing number 0 The distance (in pixels) between child elements at which they begin to merge their glass effects.
children ReactNode - LiquidGlassView children to group together.

Example

Merging Circles

import { 
  LiquidGlassContainerView, 
  LiquidGlassView 
} from '@liquid-glass/react';

function MergingCircles() {
  return (
    <LiquidGlassContainerView 
      spacing={20}
      style={{ display: 'flex', gap: 10 }}
    >
      <LiquidGlassView 
        effect="clear"
        style={{ 
          width: 100, 
          height: 100, 
          borderRadius: '50%' 
        }}
      />
      <LiquidGlassView 
        effect="clear"
        style={{ 
          width: 100, 
          height: 100, 
          borderRadius: '50%' 
        }}
      />
    </LiquidGlassContainerView>
  );
}

isLiquidGlassSupported

A boolean constant that indicates whether the current browser supports the liquid glass effect (CSS backdrop-filter).

Import

import { isLiquidGlassSupported } from '@liquid-glass/react';

Usage

Conditional Fallback

import { 
  LiquidGlassView, 
  isLiquidGlassSupported 
} from '@liquid-glass/react';

function MyComponent() {
  return (
    <LiquidGlassView
      style={{
        padding: 20,
        borderRadius: 20,
        // Fallback for unsupported browsers
        ...(!isLiquidGlassSupported && {
          backgroundColor: 'rgba(255, 255, 255, 0.5)',
        }),
      }}
    >
      Content here
    </LiquidGlassView>
  );
}

Browser Support: backdrop-filter is supported in 96%+ of modern browsers including Chrome 76+, Firefox 103+, Safari 9+, and Edge 79+.

useColorScheme

A hook that resolves the effective color scheme based on the provided value and system preferences.

Import

import { useColorScheme } from '@liquid-glass/react';

Signature

function useColorScheme(
  colorScheme?: 'light' | 'dark' | 'system'
): 'light' | 'dark'

Example

function MyComponent({ colorScheme = 'system' }) {
  const resolved = useColorScheme(colorScheme);
  
  return (
    <div className={`theme-${resolved}`}>
      Current theme: {resolved}
    </div>
  );
}

useGlassEffect

A hook that computes the CSS styles for the liquid glass effect based on the provided options.

Import

import { useGlassEffect } from '@liquid-glass/react';

Options

Option Type Description
effect 'regular' | 'clear' | 'none' Effect mode
colorScheme 'light' | 'dark' Resolved color scheme
tintColor string Optional tint color
interactive boolean Enable interactive styles
interactiveState { isHovered, isPressed } Current interactive state

useInteractive

A hook that manages interactive state (hover/press) for glass components.

Import

import { useInteractive } from '@liquid-glass/react';

Returns

{
  state: { isHovered: boolean, isPressed: boolean },
  handlers: {
    onMouseEnter,
    onMouseLeave,
    onMouseDown,
    onMouseUp
  }
}

TypeScript Types

All types are exported for TypeScript users.

Import

import type {
  LiquidGlassViewProps,
  LiquidGlassContainerViewProps,
  GlassEffect,
  ColorScheme,
} from '@liquid-glass/react';

Type Definitions

type GlassEffect = 'clear' | 'regular' | 'none';

type ColorScheme = 'light' | 'dark' | 'system';

interface LiquidGlassViewProps 
  extends HTMLAttributes<HTMLDivElement> {
  interactive?: boolean;
  effect?: GlassEffect;
  tintColor?: string;
  colorScheme?: ColorScheme;
  children?: ReactNode;
}

interface LiquidGlassContainerViewProps 
  extends HTMLAttributes<HTMLDivElement> {
  spacing?: number;
  children?: ReactNode;
}
