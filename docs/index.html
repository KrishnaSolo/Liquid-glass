Features

✨

iOS 26 Liquid Glass

Authentic glass effect using CSS backdrop-filter with blur, saturation, and brightness adjustments.

🎨

Customizable Tints

Apply any color tint to your glass elements for branded or themed interfaces.

🔧

Three Effect Modes

Choose between regular, clear, or none effects with smooth animated transitions.

🌓

Dark Mode Support

Automatic system preference detection or manual light/dark scheme control.

👆

Interactive Effects

Built-in hover and press effects with scale transforms and shimmer animations.

📦

Tiny Bundle

Only ~11KB minified with tree-shaking support. No external dependencies.

Installation

1. Install the package

npm install @liquid-glass/react

2. Import and use

import { LiquidGlassView } from '@liquid-glass/react';

function MyComponent() {
  return (
    <LiquidGlassView
      style={{ padding: 20, borderRadius: 20 }}
      effect="regular"
      interactive
    >
      <span>Hello Glass!</span>
    </LiquidGlassView>
  );
}
